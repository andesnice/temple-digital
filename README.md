# 韋銘 ｜ 宮廟數位化 ‧ 個人介紹網站

維護工程師 ‧ 宮廟資訊人員 ‧ 兩寶爸。

唯一同時懂宮廟文化、懂傳統現場、又能低成本動手做自動化的人。以模組化系統服務宮廟——報名、財務報表、內部管理、LINE 通知，而且有人固定顧著。

底層技術：n8n（自架）+ Google Apps Script + Notion + LINE Bot。

- 我的護城河
- 做過的事（玄門真宗旗艦案例、四大模組、系統架構圖）

- 常見疑慮
- 聯絡方式
