# 韋銘 ｜ 宮廟數位化 ‧ 個人介紹網站

維護工程師 ‧ 宮廟資訊人員 ‧ 兩寶爸。

唯一同時懂宮廟文化、懂傳統現場、又能低成本動手做自動化的人。以模組化系統服務宮廟——報名、財務報表、內部管理、LINE 通知，而且有人固定顧著。

底層技術：n8n（自架）+ Google Apps Script + Notion + LINE Bot。

## 內容

- 實際成果數字（跨活動資料源、每日關帳速度、驗證規模）
- 2026 年 10 月近期專案：收支流水帳、祖先超渡、祭祖公桌、藥師燈、海洋宗教活動與 LINE AI 記帳
- 玄門真宗完整案例與六段工作路徑
- 每日關帳、各活動財務稽核、報名表產生器、信眾關懷系統
- 系統架構與文件／測試／驗收流程
- 買斷建置＋三個月保固
- 網路設備設定檔產生器、其他工具實驗與 Notion 公開作品集
- 常見疑慮與聯絡方式
